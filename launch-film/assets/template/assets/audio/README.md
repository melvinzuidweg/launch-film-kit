# Audio

- `sfx/` is generated by `python tools/audio/synth_sfx.py` (numpy only, seeded, no samples, so
  no licence to track). The WAVs are git-ignored because they are reproducible.
- `licensed/` is where downloaded music goes. It is git-ignored on purpose: licensed music must
  never be committed or redistributed. Keep the licence code and credit line for each track in a
  private note, not in this repository.

Music workflow (details in the kit's references): choose the track before polishing the film;
read its BPM and find its drop with `tools/audio/find_drop.py`; set `T.SCALE` in
`src/timeline.js` if the film grid and the track tempo differ (for example 120 / 110); write an
EDL (`tools/audio/edl.example.json`) and mix with `tools/audio/mix_edl.py`.
For a dry run without music: `python tools/audio/make_test_track.py` writes a 120 BPM test track
that matches `edl.example.json`. For a film with sound effects only, set `"music": null` in the
EDL and `"target_tp": -2.0` (the kit's references/06-music-and-sound.md §10 explains the loudness
an effects-only mix can reach).
